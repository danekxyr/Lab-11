* **Тема:** Массивы как параметры функций

## Назначение файлов проекта

* **`main.c`** — демонстрация передачи массива по указателю с модификатором `const int a[]` и его длины `n` в функции `sum` и `print_array` (полный массив, префикс и пустой срез `n = 0`).
* **`self.c`** — реализация функции `count_above(const int a[], int n, int limit)`, подсчитывающей количество элементов массива, строго превышающих значение `limit`.
* **`tests.txt`** — протокол обязательных и собственных граничных тестов с ожидаемыми и фактическими результатами.

## Ограничения входа и правила

* Размер массива вычисляется в `main` через `sizeof a / sizeof a[0]` и передаётся в функции отдельным параметром `int n`.
* Модификатор `const` запрещает изменение элементов исходного массива внутри функций.
* При `n = 0` циклы не выполняются, и функции корректно возвращают `0`.

## Команды сборки (PowerShell / Bash)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o lab11
gcc -std=c11 -Wall -Wextra -Wpedantic self.c -o self
```

```text
n=0, limit=0 -> 0

```
